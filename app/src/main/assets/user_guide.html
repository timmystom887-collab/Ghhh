1. NOUS RESEARCH HERMES AGENT PROTOCOL & XML TOOL CALLING

The HermesAgentLoop implements Nous Research's ChatML standard for zero-shot function calling, multi-turn tool loops, and internal scratchpads:

<tools> JSON-Schema Tool Definitions

Available functions are injected as formatted JSON Schemas enclosed within <tools>...</tools> in the system instruction.

<scratchpad> Internal Monologue

The agent writes its planning, intermediate hypotheses, and state evaluations inside <scratchpad> tags without cluttering user-facing text.

<tool_call> Dynamic Dispatch

When an action is required, Hermes emits <tool_call>{"name": "...", "arguments": {...}}</tool_call> which is parsed and executed directly by Android binders.

<tool_response> Observation Feedback

Execution results are returned as structured <tool_response> blocks, allowing multi-turn convergence until the goal is fully satisfied.

3. WORKMANAGER BATTERY MONITOR & POWER GOVERNANCE

Continuous on-device AI operations require strict power budgeting. The BatteryAwareWorkManager continuously audits system power telemetry and enforces automated execution policies:

LOW BATTERY Automated Throttling

When battery level reaches ≤ 20% (and device is not charging), non-essential background tasks (Idle API Node Audits and Local SLM Weight Downloads) are instantly paused to preserve system stability and prevent thermal throttling.

POWER RESTORED Constraint Re-Enqueue

When charging commences or battery rises above 20%, background workloads are automatically re-enqueued with Constraints.Builder().setRequiresBatteryNotLow(true).
